# Research Agenda

PAR explores practical applications of AI in cybersecurity. Current research focuses on security operations, agentic systems, adversarial testing, and evaluating the reliability of AI-enabled security systems.

## Research Areas
- AI-Enabled Security Operations
- Agentic Security Systems
- MCP and Tool Security
- AI System Evaluation
- Adversarial Testing
- Human-in-the-Loop Security Operations

## Research Approach
Learn → Build → Instrument → Benchmark → Adversary Emulation → Measure → Harden → Re-test

## Research Questions
- How effectively can AI assist with security investigations?
- How reliably can AI systems select and use security tools?
- How well do AI-generated conclusions remain grounded in observable evidence?
- How does performance change under adversarial conditions?
- Which controls improve reliability and reduce failure modes?
- When should human review or approval remain required?

## Evaluation Dimensions
- Investigation accuracy
- Evidence grounding
- Tool-selection accuracy
- Investigation completeness
- Hallucination rate
- Adversarial resilience
- Human correction requirements
- Time to assessment
- Cost per investigation

## Current Scope
Initial work will focus on a controlled security lab containing instrumented victim systems, attacker infrastructure, centralized telemetry, security tooling, and AI-accessible interfaces such as APIs and MCP servers.

The goal is to create repeatable scenarios that allow AI-assisted security workflows to be benchmarked, attacked, hardened, and re-tested.

## Status
This research agenda is evolving as the lab and supporting tooling are developed. Results, methodologies, and implementation details will be published as individual projects mature.
